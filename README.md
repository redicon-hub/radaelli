# Radaelli Refined

REDESIGN COMPLETO SITO WEB RADAELLI LEVABOLLI

Devi progettare il redesign completo del sito:

https://www.radaellilevabolli.com/

Il progetto riguarda un'azienda consolidata e già molto ben posizionata sui motori di ricerca.

NON realizzare un sito one-page.

Il sito dovrà avere una HOME PAGE completa e numerose PAGINE INTERNE dedicate ai singoli servizi, mantenendo l'attuale architettura informativa e soprattutto gli URL esistenti.

OBIETTIVO DEL PROGETTO

Trasformare il sito attuale in un sito automotive contemporaneo, premium, altamente tecnologico e fortemente orientato alla conversione.

Il nuovo sito deve trasmettere immediatamente:

altissima specializzazione tecnica;

esperienza;

precisione artigianale;

tecnologia;

professionalità;

affidabilità;

rapidità di intervento;

cura delle automobili;

capacità di gestire completamente il problema del cliente.

NON deve sembrare una classica carrozzeria.

NON deve avere l'aspetto del tipico sito di un'officina meccanica.

Deve sembrare il sito di un centro automotive specializzato di fascia alta.

L'ispirazione visiva deve avvicinarsi maggiormente al mondo:

premium automotive + motorsport + detailing + tecnologia + precision engineering.

VINCOLO FONDAMENTALE: SEO + AEO

Il sito attuale è già molto ben indicizzato.

NON modificare arbitrariamente:

URL;

slug;

gerarchia delle pagine;

contenuti SEO rilevanti;

H1;

H2 strategici;

FAQ;

testi che rispondono a query specifiche;

struttura editoriale del blog;

collegamenti interni rilevanti.

La nuova interfaccia deve essere progettata SOPRA l'attuale patrimonio SEO.

Il redesign deve migliorare:

AEO

Core Web Vitals

senza sacrificare il posizionamento già ottenuto.

ATTENZIONE A PAGINE OBSOLETE

Durante l'analisi del vecchio sito potrebbero essere presenti URL derivanti da vecchi template WordPress o demo, ad esempio pagine generiche relative a servizi meccanici che non rappresentano realmente Radaelli Levabolli.

NON utilizzare automaticamente queste pagine come parte della nuova struttura.

La struttura principale deve essere ricavata dalle pagine reali presenti nella navigazione e dai contenuti effettivamente collegati all'attività.

POSIZIONAMENTO PRINCIPALE

Il servizio che deve dominare la comunicazione è:

RIPARAZIONE AUTO GRANDINATE CON TECNICA LEVABOLLI / PDR

Radaelli deve diventare visivamente percepito come:

"Lo specialista a cui affidare un'auto danneggiata dalla grandine."

Il secondo grande elemento distintivo deve essere:

GESTIONE COMPLETA DEL SINISTRO DA GRANDINE.

Il cliente non deve percepire di dover semplicemente "portare l'auto dal carrozziere".

Deve percepire un servizio completo:

Questo percorso deve diventare uno degli elementi chiave della nuova esperienza utente.
